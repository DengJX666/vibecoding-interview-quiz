# Vibe Coding · AI 全栈面试刷题程序

根据 AI 全栈 / Vibe Coding 岗位的常见面试要求整理的刷题工具，共 **158 道题**，覆盖 12 个模块。

其中包含：

- 122 道基础与进阶选择题/判断题
- 20 道高难题（K8s 排障、Helm、CI/CD、Vue2 原理、Node、RAG、系统设计等）
- 16 道口述简答题（自我介绍、项目深挖、AI 工作流、故障排查、私有化交付、职业规划等）

## 怎么打开

直接双击 `index.html`，用 Chrome / Edge 打开即可，不需要安装任何依赖、不需要联网。

如果浏览器限制本地文件存储，可以在当前目录执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

想部署到网上、用手机随时访问，见 [DEPLOY.md](DEPLOY.md)。

## 功能

- **四种题型**：单选题、多选题、判断题、简答题（口述题）
- **概率标注**：每题显示“被问：高 / 中 / 低”，并可按概率筛选
- **难度标注**：每题显示“基础 / 进阶 / 高难”，并可按难度筛选
- **即时判分**：选择题点击“提交答案”后，立即显示正确还是错误
- **完整解析**：无论答对答错，题目下方都展示正确答案和详细解析
- **简答题自评**：先自己口述回答，再点“查看参考答案”；对照后点“记住了”或“没记住”，没记住的自动进入错题
- **分类练习**：AI 编程工具、Prompt 与代码审查、Kubernetes/Helm、DevOps、前端、Node/Python、监控、私有化交付、系统设计、岗位软技能、AI Agent/RAG/MCP、口述与项目
- **筛选**：按分类、题型、概率、难度、状态（未做 / 错题 / 收藏）筛选
- **随机顺序**：打乱题目顺序，避免背题号
- **题目列表**：用颜色标记当前题、已答对、已答错，可点击跳转
- **错题本**：自动记录答错和“没记住”的题，点“错题”即可集中复习
- **收藏**：星标重点题
- **自动保存**：答题记录、收藏、筛选条件保存在浏览器 localStorage，关闭后再打开还在
- **重做**：已提交的题可以点“重做本题”重新作答
- **快捷键**：数字键 1-9 选择选项，Enter 提交/下一题/查看答案，← → 切换题目；简答题查看答案后按 1 记住了、按 2 没记住

## 概率和难度怎么理解

| 标注 | 含义 |
|---|---|
| 被问：高 | 岗位核心考点，面试大概率会问，必须能脱口而出 |
| 被问：中 | 常见考点，可能换一种问法出现 |
| 被问：低 | 加分项或细节题，时间充裕再看 |
| 基础 | 概念和定义，必须掌握 |
| 进阶 | 需要结合项目或场景回答 |
| 高难 | 追问、排障、原理或设计题，拉开差距用 |

## 怎么添加或修改题目

编辑 `questions.js`，在数组里追加一个对象。

选择题示例：

```js
{
  id: 'k8s-26',                 // 唯一 id，不要重复
  level: '高',                   // 被问概率：高 / 中 / 低
  difficulty: '进阶',            // 难度：基础 / 进阶 / 高难
  category: 'Kubernetes / Helm', // 分类名，建议复用已有分类
  type: 'single',                // single 单选 / multiple 多选 / judge 判断 / open 简答
  question: '题干……',
  options: ['选项A', '选项B', '选项C', '选项D'],
  answer: [1],                   // 正确选项下标，从 0 开始；多选写多个，如 [0, 2]
  explanation: '详细解析……'
}
```

判断题固定写法：

```js
{
  id: 'xxx-01',
  level: '中',
  difficulty: '基础',
  category: '岗位与软技能',
  type: 'judge',
  question: '……',
  options: ['正确', '错误'],
  answer: [0],                   // 0 = 正确，1 = 错误
  explanation: '……'
}
```

简答题写法（没有选项，用 `answerText` 存参考答案）：

```js
{
  id: 'open-17',
  level: '高',
  difficulty: '高难',
  category: '口述与项目',
  type: 'open',
  question: '……',
  options: [],
  answerText: '1. 第一点……\n2. 第二点……\n3. 第三点……',
  explanation: '记忆要点：……'
}
```

`answerText` 里可以用 `\n` 换行，页面会按行展示，方便分点记忆。

保存后刷新页面即可生效。如果改了题目的 id，本地旧的答题记录会对不上，建议清空一次记录。

## 刷题建议

1. **第一遍按“高概率”刷**：先把面试最可能问的题过一遍，重点看解析。
2. **第二遍按分类补“中概率”**：尤其是 K8s、DevOps、AI 工具三块。
3. **第三遍刷“高难”**：只做高难题，练习追问和排障思路。
4. **简答题单独练**：先自己开口说，再看参考答案，最后用自己的话复述一遍。
5. **考前只看“错题”和“收藏”**：不要重新刷全部。

## 说明

题库是按 AI 全栈 / Vibe Coding 岗位的常见面试考点整理的**练习材料**，不是面试原题。技术细节（尤其是 K8s、Helm、CI/CD 的具体命令和参数）建议结合自己实际做过的项目来回答，面试时用自己的话讲出来，比背答案更重要。
